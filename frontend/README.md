# Tic Tac Toe — игра для двух игроков

Веб-приложение для игры в крестики-нолики на одном устройстве. Два игрока по очереди делают ходы на игровом поле размером 3×3. Приложение автоматически определяет победителя или ничью.

## Технологии

- **React 19** — создание пользовательского интерфейса.
- **TypeScript** — типизация приложения.
- **Vite** — сборка и запуск проекта.
- **Material UI (MUI)** — библиотека компонентов интерфейса.
- **Vitest** — тестирование.
- **React Testing Library** — тестирование взаимодействия с интерфейсом.
- **user-event** — имитация действий пользователя.

## Возможности

- Игровое поле размером 3×3.
- Игра для двух игроков на одном устройстве.
- Автоматическое чередование ходов X и O.
- Проверка победы по строкам, столбцам и диагоналям.
- Определение ничьей.
- Подсветка выигрышной комбинации.
- Блокировка занятых клеток.
- Запрет ходов после окончания игры.
- Отображение текущего игрока.
- Перезапуск игры.

## Запуск проекта

Перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

После запуска Vite выведет адрес локального сервера в терминал. Откройте его в браузере.

## Сборка проекта

Для проверки TypeScript и создания production-сборки выполните:

```bash
npm run build
```

Результат сборки сохраняется в папке `dist`.

## Тестирование

Для запуска всех тестов выполните:

```bash
npm test -- --run
```

В проекте используются два набора тестов.

### Тесты игровой логики — `gameLogic.test.ts`

Проверяются:

- Победа по строкам.
- Победа по столбцам.
- Победа по диагоналям.
- Определение ничьей.
- Проверка пустого поля.
- Выполнение допустимого хода.
- Запрет хода в занятую клетку.
- Проверка выхода за границы поля.
- Запрет хода после победы.

Всего: 9 тестов.

### Тесты интерфейса — `App.test.tsx`

Проверяются:

- Отображение девяти клеток.
- Выполнение хода.
- Запрет повторного хода в занятую клетку.
- Определение победителя.
- Определение ничьей.
- Блокировка клеток после победы.
- Перезапуск игры.

Всего: 7 тестов.
